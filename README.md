# Vista de Doctores
Este proyecto brinda a los doctores que inician sesión, una documentación muy clara sobre su información y datos calculados. 

# Tecnologías
HTML, CSS, JavaScript y PureCSS.

# Instalación
Para ejecutar este proyecto de forma local, siga los siguientes comandos:

git clone https://github.com/GonzaloTafur/VistaDoctores.git
cd VistaDoctores
npm install
npm run dev

# Uso
Se han creado credenciales simuladas para el login, estas son "johndoe" (usuario) y "john123" (password), al ingresar, te va a dirigir a la vista principal, en la cual se encuentra una tabla con la información de los días registrados, y debajo está el resumen de la facturación, con el total de horas trabajadas y el total a cobrar.
